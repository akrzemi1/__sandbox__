== Concept _c-string-holder_ [concept.ntcts]

[subs=+quotes]
----
template<typename T>
  concept __c-string-holder__ = 
    ranges::contiguous_range<T> &&
    ranges::sized_range<T> &&
    requires(const T & t) { 
      typename T::value_type;
      { t.c_str() } -> same_as<const typename T::value_type*>;
      requires same_as<ranges::range_value_t<T>, typename T::value_type>;
    };
----

Given a `t` of type `const T&`, `T` models `__c-string-holder__` only if `t.c_str()` points to an NTCTS (https://eel.is/c++draft/intro.defs#defns.ntcts[[defns.ntcts\]]).
